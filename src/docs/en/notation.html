Notation

Every page here uses the same symbols and the same conventions. This is the list, and the parameters of the machine the figures run on.

Conventions, fixed everywhere

These hold on every page. A page that needs a different one says so in its own text.

  • Amplitude-invariant scaling. The Clarke transform carries the 2/3 factor, so α and β hold the phase peak. Power is then 3/2 (v_d i_d + v_q i_q). The power-invariant convention scales by √(2/3) and has no factor — neither is wrong, and mixing them is.
  • α lies along phase a. β leads α by 90°.
  • d lies along the rotor flux, q leads d by 90°.
  • θ is measured from α, positive counter-clockwise.
  • Positive i_q makes positive torque on a machine with the rotor turning positive. Negative i_d weakens the field.
  • Duty is 0 to 1, centre-aligned, with the pulse centred on the middle of the period — so the null vector straddles the boundary.
  • Currents are per phase, and so are R_s, L_d and L_q. A line-to-line measurement is two windings in series.
