FOC 并非一串孤立知识点的罗列，而是一个各环节相辅相成、缺一不可的闭环。下图中的每个模块都对应独立的一页——点击任意模块即可跳转阅读。

目录

  1. 01

    基础

    将任意三相物理量解读为一个旋转空间矢量，并对驱动系统进行标幺化与定标，确保运算绝不溢出。

    • 空间矢量 旋转磁场从何而来，以及为什么仅用两个数就能完整描述三相系统。
    • 三相功率 为什么单相功率会脉动过零，而三相总功率却恒定不变，以及系数 3/2 的真正来源。
    • Clarke 与 Park 变换 从 abc 到 αβ 再到 dq 的坐标变换、系数 2/3 的来历，以及角度误差带来的代价。
    • 标幺值与缩放 标幺化基准值、定点数格式，以及如何合理选型以防止运算溢出。
  2. 02

    电机

    在 abc、αβ 与 dq 坐标系之间双向自如切换，并明确每一步变换所需的角度。

    • PMSM 的 dq 模型 四个核心电机参数、dq 轴电压方程，以及在实测参数时如何避免遗漏换算系数。
    • 电机参数测量 四个电机参数的实测方法、极易遗漏的换算系数，以及温升与磁饱和对参数的影响。
    • 转矩与 MTPA 永磁转矩与磁阻转矩的机理，以及为什么 id = 0 并非总是最大转矩电流比（MTPA）最优解。
    • 弱磁控制 当反电动势逼近直流母线电压、负向 id 从“可选项”变为“必选项”时的弱磁控制策略。
  3. 03

    逆变器

    预测电机所需的端电压、输出的电磁转矩，以及转速在何处触及电压极限。

    • 三相桥 六个开关管、一套互补门极时序：当前究竟哪只器件在续流或导通，以及由此产生的导通与开关损耗。
    • 六步换相 FOC 所取代的传统方案：六个固定磁势方向、14% 的固有转矩脉动，以及高出 15.5% 的输出电压。
    • 空间矢量 PWM 扇区判断、基本矢量作用时间（驻留时间），以及为什么最小-最大零序注入与 SVPWM 完全等价。
    • 死区时间 互锁死区时间带来的输出电压失真，以及死区补偿算法实际能挽回多少损失。
  4. 04

    传感与测量

    将电压指令转化为门极驱动信号，并补偿死区时间夺走的电压。

    • 电流测量 单电阻、双电阻与三电阻采样方案，采样时刻的选择，以及各类传感器误差在 dq 坐标系中留下的特征谐波。
    • 模数转换器 有限的 ADC 量化码值对电流采样的影响，以及为什么 dq 坐标系下的量化噪声统计特性不同于三相坐标系。
    • 直流母线 从电源侧看逆变桥：母线电容纹波电流、母线电压跌落，以及制动回馈能量的去向。
    • 位置传感器 各类位置传感器的真实输出特性，以及横亘在原始计数值与真实电角度之间的 d 轴零位偏移角。
  5. 05

    控制与估算

    合理布置采样时刻，确保采到的是真实的相电流平均值，而非开关换相噪声。

    • 电流环 根据电机参数直接整定 PI 增益、交叉耦合前馈解耦，以及真正有效的抗积分饱和（Anti-windup）算法。
    • 速度环与位置环 级联控制为何有效、内外环带宽必须拉开多大差距，以及每次启动必遇的转速环饱和问题。
    • 采样时间 数字控制器本质上是差分方程：它究竟使用了哪一拍的误差采样，以及非同步采样如何引发混叠。
    • 无位置传感器估算 磁链观测器与滑模观测器（SMO）、锁相环（PLL），以及各级滤波器会将估算角度向哪个方向偏移。
  6. 06

    工程实现

    依据电机物理参数整定电流环，并防止积分器在电压受限时发生积分饱和。

    • 时序与同步 整个控制链路的延迟预算、由纯代数决定的相位裕度，以及中断服务程序（ISR）的执行时间都花在了哪里。
    • 所需外设 中心对齐 PWM、硬件触发 ADC 与刹车故障输入——微控制器硬件必须具备哪些能力，以及那些稍不留神就会踩坑的寄存器影子装载规则。
    • 软件架构 向内指向的软件分层准则、逆变器寄存器的唯一写入者原则，以及一个绝不参与控制律运算的独立“见证量”。
    • 驱动系统调试 严格按顺序逐级闭环调试，确保任何一步出现异常时都只有一个可疑原因。
