转矩与 MTPA

到目前为止，每一页都是先给定id​=0，然后再继续后续步骤。这是正确的默认设置，值得深入理解其原因；同时也要明确在哪些情况下这种做法不再适用，因为在某些电机上，若一直保持这种设置，代价会非常大。

产生转矩的两种方式

T=23​p​magnetλm​iq​​​+reluctance(Ld​−Lq​)id​iq​​​​

永磁转矩项是大家最熟悉的部分：转子磁场与定子磁场相互吸引。它与电流呈线性关系，且只需要 iq​。

磁阻转矩项则在本质上完全不同。它与永磁体无关：只要转子铁心磁路在某个方向上的磁阻比另一方向更小，转子就会受到扭力以使其易磁化轴与定子磁场对齐——就像一块未磁化的铁片会被磁铁吸过去一样。它需要两个轴上都有电流，因此与电流呈二次方关系。

这一阶次上的差异决定了本页讨论的一切。永磁转矩随电流线性增长，而磁阻转矩随电流的平方增长。在小电流下磁阻转矩可以忽略不计；而在大电流下它甚至可能占据主导地位。

最容易搞错的符号问题

对于内置式永磁电机，由于 Lq​>Ld​，因此 (Ld​−Lq​) 为负值。由此可知，只有当 id​ 为负值时，磁阻转矩项才为正。

要获得正向的磁阻转矩，必须注入负的 d 轴电流。正的 id​ 不仅浪费电流，还会反过来抵消转矩。因此，最优工作点一定位于电流平面的第二象限，绝不会在第一象限。

在试验台上 有两个指标可以判断上述特性对你的电机是否重要。第一个是凸极比 Lq​/Ld​：表贴式永磁电机为 1.0，内置式永磁电机通常为 1.5～3。第二个是特征电流 λm​/(Lq​−Ld​)，它代表磁阻转矩达到与永磁转矩相当水平时的电流尺度——参考电机为 71 A。如果你的实际运行电流远小于特征电流，那么编写 MTPA 代码根本得不偿失。

电流平面

将 id​ 水平绘制，iq​ 垂直绘制，于是所有问题都变成了几何问题。

  • 恒转矩曲线 是双曲线，因为 T=23​piq​[λm​+(Ld​−Lq​)id​]——对于给定的转矩，每一个 id​ 都需要一个特定的 iq​。在非凸极电机中，括号内没有 id​，因此等高线是水平直线。
  • 电流限制 是一个圆。它由逆变器和电机的热额定值所决定。
  • 最大转矩电流比（MTPA） 是恒转矩等高线与恒流圆相切切点的轨迹：即产生给定转矩所需的最小电流，或者等效地说，给定电流幅值下所能产生的最大转矩。

将凸极比设为 1.00，恒转矩等高线就会展平为水平直线，MTPA 轨迹完全重合到 iq​ 轴上，MTPA 带来的额外收益归零。这证明了在表贴式永磁电机上 id​=0 严格最优——这并非人为约定，而是数学推导的必然结果。

接着调高凸极比，观察 MTPA 轨迹如何向左侧（负 d 轴方向）弯曲。

闭式解，以及一个陷阱

在固定半径的圆上最大化转矩可以得到精确解。写作 D=Lq​−Ld​：

id​=2Dλm​​−4D2λm2​​+iq2​​

无需迭代，也无需查表。计算成本很低，可以在每个控制周期内进行。

在试验台上 你更常看到的表达形式是

id​=4Dλm​​−16D2λm2​​+2∣i∣2​​

这是以电流总幅值为自变量的同一个最优解，而非以 iq​ 作为自变量。这两条公式绝不能混用：如果直接把 iq​ 当作电流幅值代入上式，算出的结果会有几毫安的偏差——小到肉眼看波形觉得完全正常，大到足以偏离真正的最优解，而且除非有独立的交叉校验，否则根本无从察觉。

该网站的实现同时包含了这两种方法，并通过一致的输入对其进行测试，验证它们最终会收敛到同一点。之所以存在这一测试，是因为本页面的早期版本确实存在这样的错误。

当 Ld​=Lq​ 时，两个公式都会自然退化为 id​=0，与物理直觉完全一致。

它在环路中的位置

MTPA 只是把原本恒为常数的 id​=0 替换成了关于 iq​ 的函数：

/* Torque request -> current references. */
float iq_ref = torque_ref / kt;             /* first cut, magnet term only */
float id_ref = mtpa_id(iq_ref);             /* the closed form above */

/* Enforce the current limit on the VECTOR, not each axis. */
const float mag = sqrtf(id_ref*id_ref + iq_ref*iq_ref);
if (mag > i_limit) { id_ref *= i_limit/mag; iq_ref *= i_limit/mag; }

其下的电流环完全不会发生变化。这就是该系统架构所带来的优势：MTPA 只是对 参考值 的调整，而下游的所有环节——PI 控制器、调制器、逆变桥——均不受影响。

在试验台上 请注意，限幅作用于空间矢量。若分别对 id​ 和 iq​ 进行钳位， 则在对角线上会使实际流过电机的电流达到预期值的 2​ 倍——这与 电流环 页面上的抗积分饱和故障属于同一类错误，发生在相同的位置。每当两个轴共享同一物理约束时，限幅就应当作用于矢量幅值。

付出的代价

MTPA 并非毫无代价，客观来看，它的缺点不多但每一个都很实在：

它依赖于你无法精确获知的电机参数。 λm​ 会随温度升高而衰减，而 Ld​ 和 Lq​ 会因铁心饱和而随电流增大而下降。向解析公式代入固定的标称参数，恰恰会在最需要 MTPA 发挥作用的大电流工况下偏离真正的最优点。因此，量产驱动器普遍使用在测功机上实测标定的二维查找表，而不是直接算解析公式。

转矩常数不再是常数。 在 id​=0 控制下，转矩就是简单的 kt​iq​，仅此而已。而在 MTPA 轨迹上，转矩与电流呈非线性（含二次项）关系，因此任何假设转矩常数恒定的外环控制器，其实际环路增益都会随工作点而变化。

它会占用电压与电流裕度。 负的 id​ 会产生与弱磁控制完全相同的削磁效果——这在高速区是好事，但在低速区则意味着产生同样的转矩需要更大的合成电流矢量。

要点回顾

  • 转矩包含磁钢产生的分量（线性，仅需iq​）和磁阻产生的分量（二次，需要两个轴）。只有后者才会使 MTPA 成为一个问题。
  • 对于 Lq​>Ld​ 的电机，产生正向磁阻转矩需要注入负的 id​。正的 id​ 反而会削减转矩。
  • id​=0 在表贴式永磁电机上确实是最佳的——这是一个结果，而非约定。
  • MTPA 的收益随电流和凸极比共同增长：在参考电机上，10 A 时仅提升 1%，40 A 时提升 12%，而在强凸极电机上则可超过 50%。
  • 动手写代码前先算一下特征电流 λm​/(Lq​−Ld​)。如果实际运行电流远小于特征电流，做 MTPA 几乎没有任何收益。
  • 对电流矢量幅值施加限幅，而不是对每个轴分别限幅。
