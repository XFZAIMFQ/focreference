弱磁控制

在 MTPA 页面中，负的 d 轴电流被视为一种优化手段——在凸极电机上可以带来几个百分点的额外转矩，而在表贴式永磁电机上则可以忽略不计。

超过某一特定转速后，它就不再是可选项。如果没有它，电机根本无法再加速。

电压不足

永磁体产生的反电动势与转速成正比。再加上电阻压降和电感压降，逆变器需要输出的电压会随转速升高而增大，直到达到 Vdc​/3​ ——此时电流环将饱和，电流下降，转矩也随之降低，电机便不再加速。

在满载转矩下首次发生这种情况时的转速即为 基速。在此转速以下，驱动系统受电流限制，转矩保持恒定；而在此转速以上，驱动系统则受电压限制，必须采取某种措施来应对。

vd​=Rs​id​−ωe​Lq​iq​,vq​=Rs​iq​+ωe​(Ld​id​+λm​)

观察 vq​ 方程中的反电动势与电感项：电机所面对的 d 轴总磁链为 Ld​id​+λm​，而其中的 id​ 是完全由我们控制的。将其设为负值，合成磁链就会减小，反电动势随之降低，所需端电压便重新回到逆变器限幅范围之内。

这就是弱磁控制：将电流分配到 d 轴（该轴不产生转矩），以换取 q 轴继续工作的电压裕度。

特征电流决定一切

将 id​ 往负方向推得足够远，d 轴合成磁链就会一直减小到零。使 d 轴磁链恰好归零所需的电流幅值称为特征电流：

ich​=−Ld​λm​​

对于参考电机，该值为 −40.5 A。驱动器能否达到这一电流，决定了电机的高速特性属于哪一类：

  • 如果 ∣ich​∣ 在电流限幅圆以内，d 轴磁链可以被完全抵消，反电动势在任意转速下都能保持有界，理论上电机的调速范围是无限的。
  • 如果特征电流在电流限幅圆以外，则在磁链被完全抵消之前电流就已经达到上限，电机存在一个硬性的最高转速上限。

大多数表贴式永磁电机属于第二类——永磁体磁场强、电感低，因此λm​/Ld​数值很大。而内置式永磁电机则被刻意设计为第一类，这也是牵引驱动系统选用它们的原因。

有两点值得注意。

电流限幅值越高，基速反而越低。 这乍看之下似乎有违直觉，但只要想到更大的电流需要消耗更多的电压——更大的电阻压降 Rs​i 和更大的电感压降 ωLi——就会明白为什么电压上限会更早到来。在同一条直流母线下，额定输出转矩更大的驱动器具有更低的基速，这并不是设计缺陷。

在基速以上，转矩随转速下降，但大致遵循 1/ω 的规律，即恒功率运行。图中的虚线是穿过基速点的理想恒功率曲线；在弱磁控制有效工作的区间内，真实包络线会紧贴这条恒功率线，直到电流限幅也同时触顶后才开始偏离并加速回落。

在试验台上 提高直流母线电压后，整个包络线会向右延伸——基速与可用电压成正比。这是扩展调速范围最经济的方式，也是牵引逆变器为何在数百伏电压下运行，而这些电机在48伏下也能正常工作的原因。

电流平面上的几何关系

以上内容可由一张图表示。在电流平面中存在两个约束条件：

  • 电流限幅是一个半径固定为 Imax​ 的圆。
  • 电压限幅是一条以特征电流附近为中心的闭合曲线，它随转速升高而不断收缩。

在基速以下时，电压曲线较大，最优工作点位于 MTPA 轨迹上，并且处于其内部。在基速以上时，两条曲线相交，最优工作点沿着它们的交线滑动，并逐渐向负的 id​ 方向移动。最终，电压曲线完全收缩到电流圆之内，此时电流限制已不再起作用。

如果这条不断收缩的电压曲线最终坍缩在电流限幅圆内部（驱动器能够达到的点），电机理论上就能无限提速；如果它坍缩在电流限幅圆外部的点上，两者的交集（可行域）最终会变为空集，此时电机便达到了绝对最高转速。

在试验台上 教科书通常忽略定子电阻，把电压极限曲线画成中心恰好在 ich​ 处的标准椭圆。这有助于建立直观理解，但在定量计算上可能偏差极大：本参考电机需要 40 A 的 d 轴电流才能抵消永磁磁链，而 40 A 流过 0.35 Ω 电阻会产生 14 V 压降——占去了 27.7 V 总电压预算的一半。正因如此，本网站的交互图严格按照包含电阻项的精确约束方程来绘制边界。

本页求解器的第一版曾直接沿着教科书的近似椭圆采样来寻找候选工作点，结果所有采样点都因违反精确电压约束而被剔除——因为近似椭圆与真实边界相去甚远。它甚至算出了“具有宽裕电流限幅的驱动器，其调速范围反而比小电流限幅驱动器更窄”这种荒谬结论，幸好有一项单元测试对比了这两种情况才将其揪出来。

在实际驱动器中的实现

文献中给出的闭式解值得了解，但实际应用中却很少采用，因为它们依赖于λm​和Ld​——这两个参数会随温度和饱和效应发生较大漂移。在高速运行时若参数设定不当，要么会导致性能无法充分利用，要么会使磁链控制失效，而后者是十分危险的。

量产驱动器几乎都改用电压反馈方案：监测电流环实际所需的电压百分比，如果接近上限，则将id​调节得更负一些，直至不再接近上限。

/* The modulation index the current loop is demanding. */
const float m = sqrtf(vd_ref*vd_ref + vq_ref*vq_ref) / v_limit;

/* Above the threshold, weaken. Below it, relax back towards MTPA. */
const float err = m - 0.95f;
fw_integrator += KI_FW * err * dt;
fw_integrator = clampf(fw_integrator, 0.0f, i_max);

id_ref = mtpa_id(iq_ref) - fw_integrator;

/* The current limit is on the VECTOR, so iq gets what is left. */
const float iq_room = sqrtf(fmaxf(0.0f, i_max*i_max - id_ref*id_ref));
iq_ref = clampf(iq_ref, -iq_room, iq_room);

这是一个围绕快速电流环的慢速外环，它完全不需要电机参数——它直接测量所要控制的量。阈值略低于1.0，以使电流环保留一定的调节能力；若将其设在极限值上，电流环将失去调节余地。

在试验台上 请注意代码的最后三行。电流限幅作用于电流矢量的幅值，因此随着 id​ 变得越来越负，留给 iq​ 的电流裕量自然减小——转矩随转速下降正是这一几何约束的直接结果，无需另外编写降转矩指令。如果对 d、q 轴分别独立限幅，对角线方向上的总电流将达到预期上限的 2​ 倍，这与抗积分饱和和MTPA页面中分析的限幅漏洞完全是同一个问题。三页内容，同一个教训：共享物理预算，就必须对合成幅值限幅。

真正重要的故障

如果在磁链减弱时驱动失去控制——例如故障跳闸、栅极驱动器关闭或角度丢失——d 轴电流会消失，磁链恢复至全值，电机突然以高速产生满幅反电动势。在48 V系统中，这只是一个小麻烦。但在以三倍基速运行的400 V牵引系统中，这意味着超过一千伏的电压会通过续流二极管出现在直流母线上，并施加到电池上。

这就是不可控发电模式，属于安全问题，而非性能问题。因此，牵引电机通常设计成特征电流处于额定电流以内：能抵消自身磁链的电机，其短路电流也有上界；故障时主动短接三相便可能成为安全响应。

要点回顾

  • 基速是指当反电动势与压降之和在额定转矩下首次达到电压限制时的转速。在此转速以下，转矩保持恒定；超过此转速，必须采取某种措施。
  • 负的 id​ 会减小磁通，降低反电动势，并释放出电压裕量。它本身不产生转矩——转矩的损失就是代价。
  • 特征电流 −λm​/Ld​ 决定了速度范围。在电流限制以内，原则上可以实现无限速度；超出电流限制，则存在硬性上限。
  • 随着电流限幅值的提高，基速反而降低，因为更大的电流会消耗更多的电阻和电感压降。
  • 应采用电压反馈来实现，而不是使用公式。因为该公式依赖于两个最容易发生漂移的参数。
  • 对合成电流矢量进行限幅，将扣除 d 轴电流后的剩余裕量分配给 iq​。
  • 如果电机有可能高速运行，应在额定范围内设计特征电流——否则在故障时会变成不受控的发电机。
