符号约定

本站所有页面均遵循同一套符号与约定。本页汇总了全部符号定义，并列出所有交互图表共同使用的参考电机参数。

全局统一约定

以下约定在全站所有页面中均成立。若某页因对比需要采用其他约定，会在正文中明确说明。

  • 等幅值变换（幅值不变缩放）。 Clarke 变换包含 2/3 系数，使 α 与 β 分量的幅值直接等于相物理量的峰值。在此约定下，三相瞬时功率为 3/2 (v_d i_d + v_q i_q)。功率不变（等功率）约定则乘以 √(2/3)，功率表达式中不再带 3/2 系数——两种约定本身都没有错，但混用就会出错。
  • α 轴与 a 相轴线重合。 β 轴超前 α 轴 90°。
  • d 轴沿转子永磁体磁链方向，q 轴超前 d 轴 90°。
  • 电角度 θ 从 α 轴算起，以逆时针方向为正。
  • 在转子正向旋转的电机中，正向 i_q 产生正向电磁转矩。负向 i_d 用于削弱气隙磁场（弱磁）。
  • 占空比取值范围为 0 到 1，采用中心对齐调制，高电平脉冲居中于开关周期中点——因此零矢量横跨在相邻周期边界上。
  • 电流均为单相电流，定子电阻 R_s、电感 L_d 与 L_q 也均为单相（相-中性点）参数。端子间的线间测量值则是两相绕组串联的结果。
